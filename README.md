# Ecommerce Dashboard Project
## Description

The Ecommerce Dashboard Project is an interactive data analytics solution built in Microsoft Excel to analyze and visualize ecommerce sales performance for the year 2022. The dashboard transforms raw sales data into meaningful business insights through dynamic charts, pivot tables, and slicers.

## Features

* Monthly Orders vs Sales analysis
* Sales distribution by gender
* Order status tracking (Delivered, Returned, Cancelled, Refunded)
* Top-performing states analysis
* Customer age and gender segmentation
* Sales channel performance comparison
* Interactive filtering using slicers

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning and Analysis

## Key Insights

* Women contributed a larger share of overall sales compared to men.
* Most orders were successfully delivered, indicating strong fulfillment performance.
* Amazon and Myntra generated the highest number of orders among sales channels.
* Maharashtra recorded the highest sales among all states.
